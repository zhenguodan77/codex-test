# 拾绪

> 一生那么冗长，把好的、坏的、领悟到的情绪，都记下来。

「拾绪」是一个情绪记录 App（Web 版 MVP）。三个页签：

| 页签 | 功能 |
| --- | --- |
| ✎ 记录 | 选一种情绪（明媚 / 阴霾 / 顿悟 / 平静），写一行字，可以拍摄当下或上传照片，也可以展开写「发生了什么」或日记，纯文字也行 |
| ⧗ 时光 | 从开始记录的那一刻到现在，所有记录按日期倒序排成时间轴，可删除 |
| ✉ 絮语 | 朋友式的 AI 对话。可新建对话、重命名、删除。AI 会参考你最近的情绪记录来陪你聊 |

## 快速开始

```bash
npm install   # 或 pnpm install
npm run dev
```

浏览器打开提示的地址即可（手机上访问同一局域网地址体验最佳，拍摄按钮会直接唤起相机）。

## AI 对话说明

- 在「絮语」页右上角 ⚙ 设置里填入 [Anthropic API Key](https://platform.claude.com/)，对话即由 Claude（`claude-opus-4-8`）驱动，浏览器直连、流式输出。
- Key 只保存在你自己浏览器的 localStorage 里，不会上传到任何服务器。
- 不填 Key 也能用：内置了一个简单的本地陪伴回复作兜底。

## 数据存储

所有记录、对话、设置都保存在浏览器 localStorage（键前缀 `shixu.`），完全本地、离线可用。照片会压缩到最长边 1280px 再保存以控制体积。localStorage 容量约 5MB，照片多了之后建议后续版本迁移到 IndexedDB。

## 技术栈

React 18 + Vite 5 + TypeScript，无后端。
