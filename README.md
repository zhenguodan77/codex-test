# 拾绪

> 一生那么冗长，把好的、坏的、领悟到的日常，都记下来。

「拾绪」是一个生活记录 App（Web / PWA）。暖中性色（燕麦底 + 玫瑰陶土）的极简界面，三个页签：

| 页签 | 功能 |
| --- | --- |
| 记录 | 拍一张照片、或写一句话（一行就好），点「完成」即发布，并自动跳到「时光」 |
| 时光 | 所有记录按日期倒序成流，点照片可看大图；每条都能「追记一笔」——对旧记录补写新的想法，随记录一起留存；可删除 |
| 絮语 | 朋友式的 AI 对话。可新建对话、重命名、删除。AI 会参考你最近的记录来陪你聊 |

## 快速开始

```bash
npm install   # 或 pnpm install
npm run dev
```

浏览器打开提示的地址即可（手机上访问同一局域网地址体验最佳，「拍摄」会直接唤起相机）。在手机浏览器里可「添加到主屏幕」，以独立 App 的形式打开。

## AI 对话说明

- 在「絮语」页右上角 ⚙ 设置里填入 [Anthropic API Key](https://platform.claude.com/)，对话即由 Claude（`claude-opus-4-8`）驱动，浏览器直连、流式输出。
- Key 只保存在你自己浏览器的 localStorage 里，不会上传到任何服务器。
- 不填 Key 也能用：内置了一个简单的本地陪伴回复作兜底。

## 数据存储

所有记录、对话、设置都保存在浏览器 localStorage（键前缀 `shixu.`），完全本地、离线可用。照片会压缩到最长边 1280px 再保存以控制体积。localStorage 容量约 5MB；写入前会先落盘再更新界面，空间不足时会提示「存储空间已满」而不会丢失正在写的草稿。照片较多时，后续版本可迁移到 IndexedDB。

## 技术栈

React 18 + Vite 5 + TypeScript，无后端。附带 PWA manifest 与图标，可安装到主屏幕。
